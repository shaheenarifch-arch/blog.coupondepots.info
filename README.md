# blog.coupondepots.info
CouponDepots blog (blog.coupondepots.info), published by seo-controller.

## How this site works
- Published with GitHub Pages from `main` (root) at https://blog.coupondepots.info (see `CNAME`).
- Articles are written into `blog/` by the blog bot in [seo-controller](https://github.com/shaheenarifch-arch/seo-controller) (site entry `blog.coupondepots.info` in `sites.json`).
- DNS: CNAME record `blog` → `shaheenarifch-arch.github.io`. Help: https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site
- `google77d0e4245e3633a5.html` is the Google Search Console verification file — do not delete.
